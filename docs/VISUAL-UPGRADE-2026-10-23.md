# 桌面视觉升级验收

本轮沿用 Aurora、Graphite、Paper 的明暗身份，将主读数、重置时间、使用节奏与平台信息分出清楚层级。参考来源与长期约束见 [设计体系](DESIGN-SYSTEM.md)。

## 实现

- 统一卡片、紧凑组件、控制中心、诊断、更新和 Insights 的文字层级、表面、边框及选中态，减少重复底板、投影和图表光晕。
- 使用跨平台系统 Text 字体及明确的中文无衬线回退；Insights 的标题、混合语言指标和控件不再回退到等宽字体的中文衬线字形。
- 修复浅色 Insights 的操作图标、预测徽章与加载文字对比度，删除重复的英文标题标签。
- 保留原生尺寸、650ms 边缘悬停等待、窗口稳定测量、焦点恢复、减少动态效果偏好及 Rust 内只读凭证边界。
- 开发预览增加可交互的合成控制中心；原生矩阵为全部 24 组布局与配色保存截图。
- 发布审计发现开发工具公告后，将 Vite 更新到 7.3.7、Vitest 更新到 4.1.12。[Vite 修复版本](https://github.com/vitejs/vite/releases/tag/v7.3.7)及 [Vitest Windows 路径修复](https://github.com/vitest-dev/vitest/security/advisories/GHSA-xp26-3454-mjgp)均来自维护方。
