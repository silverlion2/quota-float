# Vibe Usage 参考更新：自定义日期区间

状态：本地源码实现；未提交、未发布安装包。

## 参考与取舍

参考 [Vibe Usage README](https://github.com/vibe-cafe/vibe-usage-app/blob/main/README.md) 的今天、24H、7D、30D、90D、自定义日期与维度筛选能力。Quota Float 已有 Token/缓存/费用趋势、模型/项目/终端筛选和过期缓存。本轮补齐自定义日期，复用现有 React 组件和统计函数，不引入依赖。

## 用户可见行为

- 用量洞察 → 自定义：填写本地开始、结束日期后点击应用；包含结束日，若选到今天则截止当前时间。支持 1–366 个日历日，完整历史仍使用“全部”。
- 编辑草稿不会立即更改统计；空白、非法日期、倒序、未来日期或超过 366 天会提示错误，保留上次有效范围。
- 前期比较沿用现有滚动范围的等实际时长语义；跨夏令时也保持相同小时数，不声称两个区间包含相同的完整日历日。费用日均按实际经过时间折算为 24 小时，当前不足一小时按一小时计算，避免短时外推失真。
- 日期范围统一作用于本机 Token 总览、前一等长区间比较、模型/项目/终端筛选、每日趋势、分时热力图、模型账本、费用展望及 CSV/JSON/SVG 导出。JSON 另外写明实际开始时间与排他结束时间。
- 额度日历和曲线跟随选定历史日期，排除结束日次日零点，历史曲线不插入当前额度；空区间显示无本地记录，不用当前额度替代历史值。
- Codex Profile 为账户累计；本周/本月报告、当前月累计与个人重置计划保留其各自明确周期。
- 修复滚动 7/30/90 天图表丢失最早半天数据的问题；图表现在覆盖与总览相同的边界日期。统计仍以本地小时桶的起始时间选取，不声称分钟级精度。

## 数据边界与回滚

所有变化位于前端统计、展示和导出层。凭据与官方额度访问继续由 `src-tauri` 只读处理；没有新增远程同步、平台配置写入或数据持久化格式迁移。自定义选择只在当前洞察组件会话保留。撤销本次前端改动即可回退，无需处理已保存数据。
