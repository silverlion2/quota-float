# Quota Float UI/UX upgrade · 2026-10-10

本轮使用 UI/UX Pro Max 和 Impeccable 的 Operate / polish 指引，升级现有桌面界面。保留 Aurora、Graphite、Paper 及 Light/Dark 身份；不改变平台凭据、额度查询、窗口几何、650ms 边栏悬停保护或发布版本。

## 交付范围

- 共享层级：系统字体与等宽数字；平台名称 12px、读数 14px、辅助文字 11px；设置标签与表单 12px，说明 11px。Graphite 去除干扰读数的网格，主题共用语义颜色、焦点、选区与原生表单明暗。
- Float / Ring：Enter 或 Space 展开，无需鼠标；闲置时保持文字清晰。加载、未登录、不可用显示文字；低额度和可用的过期缓存增加形状提示。
- Bar / Bottleneck：保留 Top/Left/Right 与按平台数量计算的原生尺寸；提高摘要、周期和更新时效的可读性；同步状态采用图形与文字，选中项保留明确边框。
- Dashboard / Cockpit / Provider Bar / Stacked：同步标题、周期、节奏、平台列表和区块操作尺度。洞察、设置、诊断、更新与独立窗口沿用相同的阅读和操作语言。
- Taskbar：设置入口、模式说明和选中反馈纳入共享升级。Windows 原生额度图标、状态含义和任务栏行为保持原有实现，本轮没有重画原生图标。
- 设置选项增加选中勾；保存布局名称补无障碍标签。开发工作台可选择布局、主题、明暗、边缘和语言，并支持加载及紧凑状态截图。

## 实现与回退

没有新增依赖。删除被后续共享规则覆盖的重复声明，保留原有 CSS / JavaScript 包预算。代码变更限于前端展示、设计规范和 UI 测试；开始时已有的空间维护修改保留。

回退应只反向应用本轮展示文件的差异及移除新建的变体测试，保留原有 README、桌面 SOP、package.json、Cargo.toml、vite.config.ts 和空间维护脚本的工作区改动。本记录对应源码交付验收，后续版本发布的提交、产物与签名验证另记。
